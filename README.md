# Jerbear's Little Question 🧸💗

A cute one-page girlfriend proposal site. Every **No** makes the **Yes** button bigger, until it takes over the screen. **Yes** reveals a celebration with floating hearts.

## Run locally

Open `index.html` in a browser. No dependencies, account, build process, or environment variables are required.

## Deploy

Push this folder to a GitHub repository, then import that repository at [Vercel](https://vercel.com/new). Select the **Other** framework preset and leave the build command empty. The site deploys as static files.

## Personalize

Edit `index.html` to change the question, dedication and ending; edit `script.js` for the No-click messages and button growth; edit `style.css` for colours; and `assets/jerbear.svg` for the bear artwork.

No clicks, answers or personal information are sent anywhere. The **Yes** celebration runs only in the visitor's browser.
